# Product Overview

CMS Project is a content management system with a public-facing frontend and protected admin dashboard. Built for managing website content, banners, users, and roles with permission-based access control.

## Core Features

- **Public Frontend**: Homepage with banner carousel, blog listing, and individual blog posts
- **Admin Dashboard**: Protected area for content management with role-based permissions
- **Content Management**: Create, edit, publish articles with categories, tags, and featured status
- **Banner System**: Manage promotional banners with positioning (HOME_TOP, HOME_MIDDLE, HOME_BOTTOM, SIDEBAR)
- **User & Role Management**: Admin-only user management with customizable roles and permissions
- **Media Upload**: File upload system for images and assets

## User Roles

- **Admin**: Full system access including user and role management
- **Editor**: Content and banner management without user administration

## Content Workflow

- **Draft**: Work in progress, not visible to public
- **Published**: Live content visible on frontend
- **Archived**: Hidden from public but retained in system
